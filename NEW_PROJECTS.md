## Descriptions and keywords

### Agent Sandbox Escape Detector
**Description:** A black-box behavioral security scanner that fires adversarial prompts at any LLM agent's HTTP chat endpoint across six attack categories (tool access, prompt leak, API call, role confusion, indirect injection, jailbreak), running all probes concurrently and using Claude Opus 4.8 via OpenRouter as an independent judge. Produces structured scan reports with per-probe ESCAPED/SAFE verdicts, evidence excerpts, and confidence scores via a CLI with CI exit codes and a FastAPI REST interface.
**Keywords:** LLM security, AI agents, red teaming, prompt injection, jailbreak detection, sandbox escape, black-box testing, LLM-as-judge, asyncio, FastAPI, OpenRouter, CLI, CI integration

### Deep Research Report Agent
**Description:** A five-stage async research pipeline that turns a single topic into a book-length, fully-cited Markdown report: Claude Opus 4.8 decomposes the topic into sub-questions, DuckDuckGo search plus an httpx/Playwright fetcher gather sources for every question in parallel, and a report builder assembles executive summary, cited sections, and bibliography. Four depth levels (overview to academic survey) with SQLite persistence and CLI, FastAPI, and Streamlit interfaces.
**Keywords:** AI agents, deep research, research reports, Claude Opus, OpenRouter, asyncio, Python, web scraping, Playwright, DuckDuckGo, citations, FastAPI, Streamlit, SQLite

### Fine-tune vs Prompt Engineering Decision Tool
**Description:** A Python experiment harness that settles the fine-tune vs prompt-engineering question empirically: it runs zero-shot, diversity-sampled few-shot, three-round prompt optimization, and LoRA fine-tuning (phi-2 + PEFT) on your labeled dataset, then a weighted decision matrix (F1 40%, cost 25%, latency 15%, complexity 20%) recommends the winner against your budget and F1 target. Exposed via Typer CLI, FastAPI REST endpoints, and a Streamlit UI with SQLite persistence.
**Keywords:** LLM, fine-tuning, prompt engineering, LoRA, PEFT, phi-2, few-shot, zero-shot, decision matrix, evaluation, F1 score, OpenRouter, Typer, FastAPI, Streamlit

### LLM Real-World Benchmark
**Description:** An automated weekly benchmark harness that runs four real engineering tasks (FastAPI JWT auth, traceback debugging, async refactoring, Pydantic v2 schema design) across seven frontier LLMs via OpenRouter, scores every response with an independent Claude Opus judge on a weighted rubric, and publishes a sortable HTML leaderboard with per-model score, latency, and cost.
**Keywords:** LLM benchmarking, model evaluation, OpenRouter, LLM-as-judge, leaderboard, asyncio, FastAPI, SQLite, APScheduler, Claude Opus, cost tracking, Python

### Reasoning Token Efficiency Leaderboard
**Description:** An async Python benchmark that runs six thinking models (GPT-4.1, Claude Opus 4.8, Gemini 2.5 Pro, Grok-4.3, DeepSeek-R1, Kimi-K2) across 20 reasoning tasks via OpenRouter, extracts native reasoning-token counts from the generation API, and ranks models by efficiency = accuracy / reasoning_tokens × 1000 on a SQLite-backed FastAPI leaderboard.
**Keywords:** LLM benchmarks, reasoning models, token efficiency, thinking tokens, OpenRouter, asyncio, httpx, FastAPI, SQLite, LLM judge, leaderboard, evaluation

### Context Compaction Visualizer
**Description:** A docker-compose web app (FastAPI + SQLite backend, React 18 + D3.js frontend) that ingests AI-agent execution traces from LangSmith, OpenTelemetry, AgentOps, or custom JSON and visualizes how context was retained, summarized, or dropped across turns — with a token timeline, session replay with compaction diffs, cost analytics, trace comparison, and Claude-powered information-loss risk scoring.
**Keywords:** context compaction, AI agents, agent observability, context window, trace visualization, FastAPI, React, D3.js, LangSmith, OpenTelemetry, AgentOps, token analytics, information loss, Claude

### Data Pipeline Debugger
**Description:** A docker-compose web app that turns pipeline debugging into a structured AI investigation: upload Airflow, dbt, or Spark logs and artifacts, and a FastAPI backend streams Claude through hypothesis formation, evidence analysis, root-cause determination, and remediation — live over SSE into a React dashboard with confidence-scored findings and an exportable Markdown report.
**Keywords:** data pipelines, debugging, root cause analysis, Airflow, dbt, Spark, FastAPI, React, Server-Sent Events, Claude, SQLite, docker-compose

### Harness Readiness Auditor
**Description:** A CLI and web platform that audits AI agent codebases for production readiness across eight maturity dimensions — context management, tool permissions, budget controls, compaction, observability, human approval, reliability, and failure recovery. It produces color-coded 0–100 scores with line-level findings and remediation recommendations via Claude, falling back to keyword heuristics when no API key is available, with a FastAPI/SQLite backend and React radar-chart dashboard.
**Keywords:** AI agents, production readiness, code auditing, maturity scoring, Claude, Python CLI, FastAPI, React, SQLite, observability, reliability, tool permissions, cost controls

### Harness Template Library
**Description:** A Python library of ten complete, runnable AI agent harness templates (coding, research, customer support, RAG, finance operations, and more), each wiring together 15 shared infrastructure modules covering context management, SQLite memory, tool permissions, budget limits, human approval, observability, state persistence, and audit logging. Every template ships with its own Click CLI, pydantic-settings config, Docker deployment, and tests.
**Keywords:** AI agents, agent harness, Python, Anthropic, Claude, agent infrastructure, templates, CLI, SQLite, observability, human-in-the-loop, budget tracking, audit logging, Docker

### Multi-Service System Design Agent
**Description:** A docker-compose web app where Claude turns a plain product idea into a structured multi-service system design — services, API contracts, database schemas, infra plan — that you review and edit in the browser, then approve to fan out parallel Claude calls (asyncio.gather) generating complete per-service code scaffolds with live SSE progress, a file-tree explorer, and ZIP export. FastAPI + SQLAlchemy/SQLite backend, React + TypeScript + Tailwind frontend.
**Keywords:** FastAPI, React, TypeScript, Anthropic Claude, code generation, system design, microservices, asyncio.gather, Server-Sent Events, SQLAlchemy, SQLite, docker-compose, AI agent

### Tool Permission Matrix Builder & Validator
**Description:** A docker-compose web app for governing AI agent tool access: register tools across six risk categories, drag permissions onto a roles × tools matrix with three-state cells (allowed/denied/inherited), and export the policy as JSON, YAML, or a py_compile-verified Python module. A Claude-powered validator (with regex heuristic fallback) audits real agent code against the policy and a sprawl analyzer flags over-exposed roles, over-exposed tools, and unused grants.
**Keywords:** AI agents, tool permissions, RBAC, security governance, policy-as-code, FastAPI, React, Zustand, dnd-kit, Claude, SQLite, docker-compose
